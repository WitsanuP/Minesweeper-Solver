# Minesweeper Solver (OCR + คำนวณความน่าจะเป็น)

โปรแกรม C++ ที่อ่านภาพหน้าจอเกมมายสวีปเปอร์ (OCR) แล้วคำนวณ **โอกาสเป็นระเบิดของทุกช่องที่ยังไม่เปิด**
พร้อมบอกว่าช่องไหนกดได้เลย ช่องไหนเป็นระเบิดแน่นอน และถ้าต้องเดาควรเดาช่องไหน

---

## 1. ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `minesweeper_solver.cpp` | โค้ดหลัก |
| `stb_image.h` | ไลบรารีโหลดภาพ (PNG/JPG) |
| `stb_image_write.h` | ไลบรารีเขียนภาพผลลัพธ์ |
| `example_annotated.png` | ตัวอย่างภาพผลลัพธ์ |

ไลบรารี stb เป็น single-header ของ https://github.com/nothings/stb ไม่ต้องติดตั้งอะไรเพิ่ม

---

## 2. คอมไพล์

```bash
g++ -O2 -std=c++17 minesweeper_solver.cpp -o ms_solver
```

ต้องวาง `stb_image.h` และ `stb_image_write.h` ไว้โฟลเดอร์เดียวกับไฟล์ `.cpp`

---

## 3. วิธีใช้

```bash
./ms_solver ภาพ.png [ตัวเลือก]
```

ตัวอย่าง

```bash
./ms_solver pic.png --edges tr               # ขอบบน + ขวาตัน
./ms_solver pic.png --edges none             # ภาพถูกตัดทุกด้าน
./ms_solver pic.png --edges tl --density 0.156
./ms_solver pic.png --cell 30 --out result.png
```

### ตัวเลือก

| ตัวเลือก | ความหมาย | ค่าเริ่มต้น |
|---|---|---|
| `--edges X` | ด้านที่ **ตัน** (เป็นขอบกระดานจริง) ดูหัวข้อ 4 | `none` |
| `--density D` | ความหนาแน่นระเบิดโดยรวมของกระดาน (0-1) | `0.206` |
| `--cell PX` | บังคับขนาดช่อง (พิกเซล) ถ้าหาตารางอัตโนมัติผิด | อัตโนมัติ |
| `--no-flags` | ไม่เชื่อธง ถือว่าธงเป็นช่องปิดธรรมดา | เชื่อธง |
| `--out FILE` | ชื่อไฟล์ภาพผลลัพธ์ | `annotated.png` |
| `--debug` | แสดงค่าที่ใช้ตัดสินแต่ละช่องตอน OCR | ปิด |

ค่า `--density` ที่แนะนำตามระดับเกม

| ระดับ | density |
|---|---|
| Beginner (9x9, 10 ลูก) | 0.123 |
| Intermediate (16x16, 40 ลูก) | 0.156 |
| Expert (30x16, 99 ลูก) | 0.206 |

## 4. ตัวเลือก `--edges` (ขอบตัน)

ภาพที่แคปมามักเป็นแค่ **บางส่วน** ของกระดาน บางด้านเป็นขอบกระดานจริง บางด้านถูกตัดออก
ต้องบอกโปรแกรมว่าด้านไหน "ตัน" (ไม่มีช่องต่อไปอีก)

| อักษร | ความหมาย |
|---|---|
| `t` | ขอบ **บน** ตัน (top) |
| `r` | ขอบ **ขวา** ตัน (right) |
| `b` | ขอบ **ล่าง** ตัน (bottom) |
| `l` | ขอบ **ซ้าย** ตัน (left) |
| `none` | ไม่มีด้านไหนตัน ภาพถูกตัดทุกด้าน |

ใส่รวมกันได้ เช่น `tr` = บน+ขวา, `tl` = บน+ซ้าย, `br` = ล่าง+ขวา, `trbl` = เห็นกระดานทั้งใบ
หรือพิมพ์เป็นคำก็ได้ เช่น `top`, `right`, `top-right`

**ทำไมต้องบอก?** ด้านที่ไม่ตัน แปลว่าเลขที่อยู่ติดขอบภาพมีเพื่อนบ้านที่อยู่นอกภาพ
โปรแกรมจะเติม "ช่องปริศนา" 1 ชั้นนอกภาพในด้านนั้นให้ เพื่อให้คำนวณเลขขอบภาพได้ถูกต้อง
(ถ้าบอกผิดว่าตัน จะได้ผลคำนวณเพี้ยน)

## 5. อักษร/สัญลักษณ์ในผลลัพธ์

### 5.1 ตาราง OCR (`=== OCR ===`)

| อักษร | ความหมาย |
|---|---|
| `#` | ช่องที่ยังไม่เปิด |
| `F` | ช่องที่ปักธงไว้ |
| `.` | ช่องเปิดแล้วและเป็น 0 (ว่าง) |
| `1`-`8` | ช่องเปิดแล้ว เลขบอกจำนวนระเบิดรอบข้าง |

### 5.2 ตารางโอกาสเป็นระเบิด (`=== โอกาสเป็นระเบิด ===`)

| แสดงเป็น | ความหมาย |
|---|---|
| `0` | **ปลอดภัย 100%** กดได้เลย |
| `MINE` | **เป็นระเบิดแน่นอน** ควรปักธง |
| ตัวเลข เช่น `37` | โอกาสเป็นระเบิด 37% |
| `[21]` | ช่องที่ไม่ติดเลขใดเลย ใช้ค่า `--density` แทน (เป็นค่าประมาณ) |
| `F` | ธงที่ปักไว้ |
| `.` | ช่องที่เปิดแล้ว |

### 5.3 ภาพผลลัพธ์ (`annotated.png`)

ระบายสีทับเฉพาะช่องปิด พร้อมตัวเลข % อยู่กลางช่อง

| สี / อักษร | ความหมาย |
|---|---|
| เขียว + `0` | ปลอดภัย 100% |
| แดงเข้ม + `X` | ระเบิดแน่นอน |
| เขียว → เหลือง → แดง | เสี่ยงน้อย → เสี่ยงมาก (ตัวเลข = %) |
| น้ำเงินม่วง | ช่องไกลเลข ใช้ค่า density |

### 5.4 ส่วนสรุป (`=== สรุป ===`)

- **ช่องปลอดภัย 100%** รายการช่องที่กดได้เลย (แถว, หลัก นับจาก 1 เริ่มบนซ้าย)
- **ช่องที่เป็นระเบิดแน่นอน** รายการช่องที่ควรปักธง
- ถ้าไม่มีช่องปลอดภัย จะแสดง **5 ช่องที่เสี่ยงน้อยที่สุด** ให้เลือกเดา

## 6. หลักการทำงาน

1. **หาตาราง** วัดความสว่างเฉลี่ยของแต่ละคอลัมน์/แถว เส้นแบ่งช่องจะมืดกว่า
   แล้วหาขนาดช่องและตำแหน่งเริ่มต้นที่เส้นมืดเรียงสม่ำเสมอที่สุด (ไม่ต้องบอกจำนวนแถว/คอลัมน์)
2. **OCR ด้วยสี** (ไม่ใช้ template matching)
   - พื้นเข้ม = ช่องที่เปิดแล้ว, พื้นสว่าง = ช่องปิด
   - มีพิกเซลขาวจำนวนมาก = ธง
   - มีพิกเซลสีสด = เลข แล้วจับคู่กับสีมาตรฐาน (1 ฟ้า, 2 เขียว, 3 ชมพู, 4 ม่วง)
3. **สร้างเงื่อนไข** ทุกเลขให้สมการ "จำนวนระเบิดในช่องปิดรอบข้าง = เลข - จำนวนธง"
4. **แบ่งกลุ่มอิสระ** ช่องที่เกี่ยวข้องกันผ่านเลขเดียวกันอยู่กลุ่มเดียวกัน
5. **ไล่คำตอบทั้งหมด** (backtracking + ตัดกิ่ง) ของแต่ละกลุ่ม
   ถ่วงน้ำหนักแต่ละคำตอบด้วย `(density/(1-density))^จำนวนระเบิด`
   แล้วหาสัดส่วนคำตอบที่ช่องนั้นเป็นระเบิด = โอกาสเป็นระเบิด
6. **วาดผล** ลงภาพและสรุปเป็นข้อความ

## 7. ข้อจำกัด

- สีเลข **5-8** เป็นค่าที่เดาไว้ (ในภาพตัวอย่างไม่มี) ถ้าธีมต่างออกไปให้แก้ตาราง `PALETTE` ในโค้ด
- เกณฑ์แยกช่องเปิด/ปิดใช้ความสว่างพื้น (ค่า 70) เหมาะกับ **ธีมมืด** ถ้าใช้ธีมอื่นให้แก้ในฟังก์ชัน `readCell`
- ไม่ได้ใช้ "จำนวนระเบิดทั้งกระดาน" ช่องที่ไม่ติดเลขจึงได้ค่า density ตรง ๆ (ประมาณ)
- เชื่อว่าธงที่ปักถูกต้อง ถ้าปักผิดผลจะเพี้ยนหรือขึ้นเตือน ใช้ `--no-flags` เพื่อไม่เชื่อธง
- กลุ่มช่องขอบเขตที่ใหญ่มากอาจใช้เวลานาน โปรแกรมมีขีดจำกัดและจะเตือนว่าผลเป็นค่าประมาณ
- ถ้า OCR อ่านเลขผิด จะขึ้น `[เตือน]` ว่าข้อมูลขัดแย้ง ลอง `--debug` หรือ `--cell` เพื่อตรวจสอบ
